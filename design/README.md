## 三份设计事实源的关系（重要）

| 事实源 | 形态 | 状态 | 角色 |
|--------|------|------|------|
| `02_交互原型/EngForge_原型.html` | HTML 原型 | **已过时**（单字符图标/假数据/含超范围功能） | 历史参考：交互意图与信息架构 |
| Ardot 设计稿（Bento Neutral） | 云端设计文件 | **现行有效** | 视觉规范唯一事实源 |
| `src/` 已实现应用 | Next.js 代码 | **现行有效** | 落地实现，新 UI 以此为准 |

**规则**：三者冲突时，以「已实现代码 → Ardot 设计稿 → HTML 原型」为优先级。
后续深度重构原型时，新原型应基于 Ardot 设计稿重画，而非修补 HTML 原型。
