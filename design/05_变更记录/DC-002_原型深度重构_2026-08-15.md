## 5. 屏幕清单与信息架构（Phase 1 边界）

1. **v2 · Landing**：split hero（理念副标沿用 3f5f5b6 定稿文案）+ ProductPreview + 3 特性卡（借鉴起点/批改沉淀/版本回溯，lucide 图标，弃用 F/P/S 字母）
2. **v2 · Login**：居中卡；含"邮箱已验证"绿色提示与错误态示例
3. **v2 · Register**：居中卡；含"查收验证邮件"引导态 + 5s 跳转说明
4. **v2 · Dashboard**：Sidebar（我的作文 active / 收藏 / 批改请求 disabled·Phase 2 / 邀请协作）+ TopBar（铃铛徽章）+ 4 统计卡 + 作文列表（草稿/已发布 pill）+ 热力图 + 活动面板
5. **v2 · Editor**：顶栏（标题/保存状态/发布）+ 工具栏 + 正文 + 字数 + 右侧元数据与 AI 用词提示（词级替换 popover 场景 + 修改历史）
6. **v2 · Detail**：标题区 + 操作行（借鉴/收藏/提交批改）+ 三 tab（正文/版本历史/批改记录）+ 版本切换条 + 右侧版本列表（含"借鉴自 ××"来源）
7. **v2 · 批改审阅**：批改头（状态 pill 待审阅）+ 提交说明 + diff（绿增红删）+ 采纳/关闭 + "采纳后生成新版本"说明
8. **v2 · 三态规范**：空状态 / 加载中（skeleton）/ 错误（重试）三卡，任何列表/内容区必配

**裁剪清单**（不出现）：个人主页、PR 评论、作文评论、全局 PR 收件箱（Phase 2）、LLM AI（Phase 3）、探索广场页。

## 6. 视觉规格（token 级）

- 色彩：zinc 全梯度中性 + primary #3B82F6 / green #10B981 / amber #F59E0B 三系
- **豁免**：diff 语义色——删除行 red-50 底 #FEF2F2 + red-700 字 #B91C1C（与代码 PrDiffView 的 Tailwind 标准红绿一致，属语义色非装饰色）
- 卡片：r12 + bg-white + shadow-card 双层投影，无边框；输入框 r8 + zinc-200 边；tag r6 zinc-100
- 字体：Sarasa Gothic SC；H1 24/Bold、H2 20/SemiBold、H3 16/SemiBold、Body 14、Caption 12
- 图标：内联线性 SVG，对应 lucide-react（history / copy / check-circle-2 / star / bell / pen-line / file-diff / users 等）
- 画板尺寸：Desktop 1440 宽，2 行 4+4 排布，间距 120

## 9. 风险与回滚

- 风险：新组与旧屏并存期间可能误改旧屏 —— 全部操作限定新 node id 前缀，不触碰 2:xx / 12:xx
- 回滚：画布侧删除新画板组即可；代码侧零影响（本次纯设计稿）

## 10. 验收标准

1. 7 屏 + 三态规范板全部落位，无文字溢出/不可读（截图逐板验证）
2. 全站界面文案 0 处 Fork/PR/Star/Repo 英文术语（画板注释与技术说明除外）
3. 每个含列表/内容的屏可指认其三态出处（本屏或规范板）
4. 所有色值/圆角/阴影可映射到组件库 swatch（无来源不明样式）
5. 不出现裁剪清单中的任何功能
