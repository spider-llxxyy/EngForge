# DC-001 · 设计系统组件库页（Ardot）

> 日期：2026-08-15 ｜ 状态：**已批准（用户预批："立项吧，按你说的改"）** ｜ 画布：https://ardot.tencent.com/file/714864718971032

## 变更目标（一句话）

在 Ardot 源文件中新增「Design System · 组件库」页面级画板，把 Bento Neutral 已定型的 token 与组件固化为可复用资产，从"检查表防漂移"升级为"复制已固化之物防漂移"。

## 背景与动机

- 画布现状：6 个页面级屏幕（Dashboard / Landing / Login / Register / Editor / Detail），**零变量定义**，所有样式逐屏手写——这是风格漂移的结构性根源。
- 代码侧 token 已定稿（globals.css @theme），但画布侧没有对应资产；新页面设计每次"凭记忆重画"。

## 画板内容规划（token 级规格）

### 01 色彩
- Primary：#3B82F6 / #2563EB / #DBEAFE / #EFF6FF
- Green：#10B981 / #059669 / #D1FAE5
- Amber：#F59E0B / #D97706 / #FEF3C7
- Zinc（中性唯一来源，禁 gray）：50 #FAFAFA / 100 #F4F4F5 / 200 #E4E4E7 / 400 #A1A1AA / 600 #52525B / 800 #27272A / 900 #18181B

### 02 排版
- H1 24/700 zinc-900 · H2 20/600 zinc-900 · H3 16/600 zinc-900 · 正文 14/400 zinc-700 · 辅助 12/400 zinc-500

### 03 形状与阴影
- 卡片 = cornerRadius 12 + fill #FFFFFF + DROP_SHADOW（y1 r2 a0.08 + y1 r3 a0.05），**无边框**
- 小圆角元素（tag/input）：cornerRadius 6-8

### 04 组件（含状态）
1. **Button**：primary（#3B82F6 白字）/ secondary（白底 zinc-200 边）/ ghost / disabled（zinc-100 底 zinc-400 字）
2. **Status Pill**：草稿（amber-light 底 amber-dark 字）/ 已发布（green-light 底 green-dark 字）/ 待审阅（primary-light 底 primary-dark 字）/ 已合并（green 实底白字）
3. **Tag chip**：zinc-100 底 zinc-600 字，r6
4. **Input**：label + 输入框（白底 zinc-200 边 r8）+ 辅助文案
5. **Sidebar Nav Item**：默认（透明底 zinc-600）vs active（#EFF6FF 底 #2563EB 字）——对应 Pill 风格
6. **Stat Card**：数值 24/700 + 标签 12 zinc-500 + 涨跌标识（涨 #10B981 / 跌用 amber，遵中国行情惯例红色系不适用非金融场景，增长绿）
7. **Toast**：成功（green-light 底 + green-dark 图标）/ 失败（amber 系）——sonner 风格
8. **EmptyState**：图标 + 主文案 + 次文案 + 主按钮
